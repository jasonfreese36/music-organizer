# v1.5 音频精调

[English](AUDIO_TUNING.md) · [项目首页](../README.zh-CN.md)

进入“**高级设置 → 音频精调**”。首次使用仍沿用原有处理默认值：SWR、保留 PCM 原采样率、普通 DSD 转换、不调整增益、不启用自定义 cutoff。设置保存在本地，也会包含在导出的整理配置中。

## 重采样选择

| 引擎 / 滤波 | 可调内容 |
|---|---|
| **SoXR** | HQ 20-bit、VHQ 28-bit，或自定义 15–33-bit 计算精度；可选 Chebyshev |
| **SWR · Kaiser** | 加窗 sinc；滤波长度 4–256、相位表精度 0–16、Kaiser β 2–16、精确有理数采样比 |
| **SWR · Blackman–Nuttall** | 使用另一种窗函数的 sinc；可调 SWR 长度和相位表 |
| **SWR · Cubic** | 三次插值，提供速度优先的选择 |

计算精度与输出文件位深分别设置。“相位表精度”不是最小相位 / 线性相位切换。当前引擎不用的控件会禁用。

勾选“**自定义 cutoff 截止比例**”后，初始值为 **98%**，可在 80–99.7% 内调整。比例相对于适用的奈奎斯特频率：SWR 定义 −6 dB 截止点，SoXR 定义 0 dB 通带点；两个引擎的相同比例并不代表相同频响。关闭自定义时沿用引擎默认。参数定义见 [FFmpeg 重采样文档](https://ffmpeg.org/ffmpeg-resampler.html)。

输出采样率策略在“**音频转换**”中选择。只改变滤波参数，不会让保留原采样率的现有 FLAC 重新编码。“**按 44.1 / 48 kHz 家族降低**”会尽量保留整倍数关系，例如上限 96 kHz 时，176.4 kHz 降至 88.2 kHz，192 kHz 降至 96 kHz。编码器与苹果设备的兼容限制仍优先生效。

## 抖动与电平

需要量化时，在最后的整数输出阶段添加抖动。可选矩形、三角、高通三角，以及内置引擎支持的噪声整形。噪声整形不支持目标采样率时会报错，避免底层静默改用其他方法；三角抖动支持所有可选采样率。抖动幅度默认 1，设为 0 不添加抖动噪声。

“**输出增益 / 预留余量**”是固定的 −24 至 +6 dB 调整，默认 0。负值预留余量，正值可能削波。程序不会自动归一化响度或限幅。可选的“混缩矩阵归一化”减少多声道混缩的矩阵过载，不等于真峰值限幅器。保留原编码的 MP3/AAC 只有启用重新编码后才应用电平调整。

## DSD → PCM

勾选“**启用 DSD 高级处理**”后，DSF、DFF 与 SACD ISO 使用同一条链路；ISO 先提取 DSD，必要时解码 DST。FFmpeg 的 DSD 解码器使用固定 FIR，本版开放的是解码后的 PCM 处理参数。

| 控制项 | 实际行为 |
|---|---|
| **PCM 采样率** | 44.1、48、88.2、96、176.4、192、352.8、384 kHz，在“音频转换”中选择 |
| **DSD 的 PCM 位深** | FLAC 可选 16 / 24 / 32 bit；ALAC 按苹果设备限制处理 |
| **DSD 独立增益** | −24 至 +12 dB，与输出增益相加；默认 0，不自动补偿 +6 dB |
| **超声低通截止** | 0 为关闭，否则为 20–100 kHz，默认 30 kHz；实际值限制在解码后 PCM 的奈奎斯特频率以内 |
| **低通阶数** | 2 / 4 / 6 / 8 阶双精度 Butterworth IIR；会影响相位响应 |
| **去除直流** | 可选 5 Hz 二阶高通 |

处理顺序为：**解码 → 去直流 / 低通 → 增益 → 最终重采样与声道映射 → 整数量化 / 抖动 → 编码**。低通在最终降采样之前执行。预览会显示实际低通截止、增益、重采样器和输出格式。

默认不启用高级 DSD 处理。普通 SACD 在原生工具支持的采样率下仍使用原来的直接 FLAC 提取方式；其他采样率会先提取 DSD，再交给 FFmpeg。源文件保留，原盘是否额外归档仍遵循当前输出预设。

## 续跑与校验

当前生效的 DSP 参数写入曲库索引。相同设置重跑会复用完成结果；修改设置后，从原始来源重建对应输出。恢复未处理的 PCM 时也读取原始来源。处理过的音频校验格式、时长和完整解码；只有预期不改变 PCM 时才进行采样数据一致校验。

测试使用生成的音频测量 cutoff 频响、DSD 增益、超声衰减和去直流，同时检查采样率、苹果设备限制及续跑。ISO 提取边界使用生成的 DSD/XML 样本验证；未宣称完成真实原盘听音对照。
